## ✨ Portfolio Website

This repository also contains my interactive light-theme portfolio built with **HTML, CSS, JavaScript and Three.js**.

### Highlights
- Interactive Three.js hero scene.
- Floating geometry, particles and orbiting Poké Ball.
- 3D Poké Ball animation in the Pokédex project.
- Low-poly Pikachu animation in the Pokédex Mobile project.
- Perspective tilt and micro-interactions across project cards.
- Responsive layout for desktop, tablet and mobile.
- `prefers-reduced-motion` support.
- Progressive enhancement: portfolio content remains visible even if WebGL/Three.js is unavailable.

### Performance
- Device pixel ratio is capped to reduce GPU load.
- Lower geometry detail is used on smaller devices.
- 3D scenes pause outside the viewport.
- Rendering pauses when the browser tab is hidden.
- Geometry/material reuse where practical.
- No build tool is required.
