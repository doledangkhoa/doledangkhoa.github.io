# Portfolio v3 UI Upgrade

This version preserves the portfolio content from v2 and focuses only on interface upgrades.

Changes include:
- premium glass navigation and active section state
- responsive mobile navigation
- stronger hero composition and dark interactive 3D panel
- bento-style featured project layout
- cleaner project, experience, skills, education and certification cards
- premium dark contact section
- improved spacing, typography, shadows, hover states and responsive behavior
- no timeline added
- no AI-related content added

Open `index.html` to preview locally.
